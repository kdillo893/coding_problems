# Algorithms

Where I put random algorithm based files. These are currently just in C.

## Building

Using Makefile for build process. Consult that for uncommon targets.
```
make all
```

'all' will clean and re-build everything. If you want small changes, just run
single modules like the following:

```
make huffman
```

## Running
Execute the file that make generated. Example:

```
./huffman
```
